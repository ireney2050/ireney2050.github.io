Data Flow & Tracking

Data will be going to Google Analytics tracking all of this or again, could be an internal system. We could have data writing to a MySQL database. It's great for aggregate things like how many sessions did I get on my site? How much traffic did I get from organic?

User Tracking & Cookies

We may track a user ID, we may have some sort of a field to say whether or not it's a repeat session or it's a new customer. We do all of this using cookies, so basically a cookie is a little snippet of code that is put in your browser when you visit a website, it has an identifier related to it.
