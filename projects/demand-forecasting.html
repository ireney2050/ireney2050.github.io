Demand Forecasting for Staffing Optimisation

Forecasting · Camp Australia · 2022–2025

📌 Overview

Developed predictive models to forecast booking demand across 500+ school sites using 4.5M+ annual booking records, enabling optimised staffing levels and capacity planning across Australia's largest OSHC provider.

🏆 Key Contributions

  • Engineered time-series features from 4.5M+ annual booking records including seasonality, school-term patterns, and local event indicators.
  • Built forecasting pipeline combining ARIMA, Prophet, and gradient boosting models to predict daily demand per school site.
  • Automated data ingestion from Snowflake, enabling daily model refresh and real-time forecast updates across all 500+ locations.
  • Reduced over- and under-staffing by providing operations managers with 2-week rolling demand forecasts and confidence intervals.
  • Created Power BI monitoring dashboards to track forecast accuracy and flag anomalous demand patterns.

🛠 Tech Stack

Python Time Series Prophet ARIMA SQL Snowflake Power BI

📈 Outcome

★ Improved demand prediction accuracy by 20%+. The forecasting system became a core operational tool, reducing labour costs and improving service quality across the national network of school sites.
